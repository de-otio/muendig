# Plural Counterpublics by Federation

> See [moves README](README.md) for orientation. This is the fourth design move.

Take Fraser's correction ([critiques](../../critiques.md)) seriously. The platform is not a single town square; it is an architecture for many publics, each self-governing, with explicit mechanisms for cross-public contestation.

Concrete features:

- Federated (ActivityPub or successor).
- Each instance/community sets its own deliberative norms.
- Cross-community threads exist and are clearly marked as such.
- No global feed.

- *Why:* No single public sphere is honest about the historical record or about contemporary plurality.
- *Cost:* Moderation quality varies by community. Incompatible norms produce incompatible discourse — by design.

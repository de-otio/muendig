# Communicative-Action Affordances Built In

> See [moves README](README.md) for orientation. This is the third design move.

The composer treats different speech-act types differently. Distinguish *assertion of fact*, *expression of opinion*, *normative claim*, *sincere personal expression* — at least in the structure offered to authors. Replies are encouraged to engage with the validity claim being made (truth, rightness, sincerity, intelligibility).

Concrete features:

- Optional steel-man prompts ("write the strongest version of the position you disagree with before replying").
- Structured "I think the premise of this argument is X — do you accept that premise?" reply templates.
- An explicit *agreement found* affordance to mark when a thread reaches resolution rather than only when it dies.

- *Why:* These nudges privilege orientation toward understanding over orientation toward winning. (See [communicative-action](../../communicative-action.md) for the underlying distinction.)
- *Cost:* Friction. Users who want to express, not deliberate, find the platform preachy.

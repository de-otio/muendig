# Non-Lord Editorial Gatekeeping

> See [moves README](README.md) for orientation. This is the fifth design move.

The professional press's filtering function — flagged as lost in Habermas's [2022 update](../../further-transformation-2022.md) — is reconstituted in distributed, accountable forms.

Concrete features:

- Community-elected moderators with bounded terms.
- Transparent moderation logs.
- Appeals heard by a different moderator than the one who acted.
- *Curator* roles distinct from *moderator* roles (curators surface salient discussions; moderators handle norm violations).
- Curator selections are themselves discussable.

- *Why:* Some gatekeeping is necessary for deliberative quality; the question is whether it is accountable.
- *Cost:* Slow. Politicised. Communities will fragment over moderation disagreements.

# Open Questions

> See [README.md](README.md) for orientation. Open directions for further development.

- If the goal is plural counterpublics rather than a single public sphere ([critiques.md](critiques.md)), what does the *infrastructural* requirement become? Decentralised, federated, plural by construction (fediverse, IndieWeb)? Or something else entirely?
- Habermas's bourgeois public sphere was funded by reader-purchased periodicals — economic independence from advertising and the state. Is there a digital-era equivalent of that funding structure (reader-funded newsletters, subscriptions, micro-payments) that is congruent with the public-sphere function rather than hostile to it?
- The "editorial gatekeeping" function that Habermas (2022) flagged as lost ([further-transformation-2022.md](further-transformation-2022.md)) — can it be reconstituted in non-lord forms? Curated communities, federated moderation, reputation systems? Each has known failure modes.
- For De Otio specifically: which of Habermas's normative criteria should the org's tools be designed to satisfy, and how would compliance be measured? "Does this tool widen or narrow the path off the platforms" is one test; "does this tool support communicative or strategic action" ([communicative-action.md](communicative-action.md)) is a sharper one.
- How does the *Strukturwandel* thesis interact with the [Enlightenment lineage](../enlightenment-lineage.md)? The Enlightenment thinkers wrote *for* a public sphere they took for granted; Habermas tells us that public sphere was a specific fragile formation that has decayed. The combined diagnosis: the techno-feudal arrangement erodes both the principles (Enlightenment) and the social conditions (Habermas) on which independent creative publication depends.
